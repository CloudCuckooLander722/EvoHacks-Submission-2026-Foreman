# EvoHacks-Submission-2026-The-Daily-Brief
Repository for EvoHacks 2026, demonstrating the idea of an AI powered daily brief filtering your emails and calendar events for the high priority tasks.

# Requirements

## 1.1 Agents

### root_agent 
- The agent primarily responsible for redirecting the flow of other agents

### calendar_agent
- The agent primarily responsible for retrieving events for the daily brief

### consultant_agent
- The agent responsible for organizing tasks of importance based off ideas
